# ACT3-APPINCJAVA-2058161-LABPROWEB
Actividad 3 Aplicación Interactiva con JavaScritp 2058161

# Agenda acádemica

## Objetivo 
Desarrollar una aplicacion web del lado del cliente mediante JavaScript ES6+ , manipulación de DOM, eventos, validación de datos y persistencia local.

## Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript
* GitHub
* LocalStorage

## Funcionalidades 
* Registro de actividades
* Visualización de actividades registradas
* Editar actividades
* Eliminar actividades
* Validación de datos
* Cambio de estado (Pendiente o completada)
* Contador automático (Total de actividades, Pendientes y Completadas)
* Persistencia local (mediante LocalStorage)
